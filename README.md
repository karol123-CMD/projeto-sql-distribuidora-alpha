# Projeto SQL | Distribuidora Alpha
Projeto de banco de dados relacional em SQL para análise comercial de uma distribuidora fictícia, com modelagem, carga de dados e consultas analíticas.

Projeto SQL | Distribuidora Alpha
Sobre o projeto

Este projeto foi desenvolvido para aplicar, na prática, conceitos de modelagem de dados e análise em SQL a partir de um cenário de negócio fictício. A proposta foi estruturar um banco de dados relacional para a Distribuidora Alpha, uma distribuidora regional de alimentos e bebidas, com foco na organização de dados comerciais e no desenvolvimento de consultas analíticas voltadas à tomada de decisão.

Objetivo

O objetivo do projeto foi transformar uma necessidade de negócio em uma solução prática com SQL, passando pelas etapas de modelagem conceitual, modelagem lógica, modelagem física, carga de dados e consultas analíticas. A estrutura foi pensada para responder perguntas sobre vendas, clientes, produtos e desempenho comercial.

Estrutura do projeto

O banco foi modelado com entidades centrais como Cidade, Endereço, Supervisor, Vendedor, Cliente, Categoria, Produto, Forma de Pagamento, Pedido e Item do Pedido, refletindo a operação comercial da empresa e seus principais relacionamentos.

Tecnologias utilizadas

SQL — linguagem principal para criação da estrutura do banco e desenvolvimento das consultas;
SQLite — sistema de gerenciamento de banco de dados utilizado na modelagem física e execução dos scripts;
Draw.io — ferramenta utilizada para construção e organização do DER;
GitHub — plataforma utilizada para versionamento e publicação do projeto;
PDF — formato utilizado para documentação da contextualização, modelagem conceitual e modelagem lógica.
Principais análises desenvolvidas

Entre as análises construídas no projeto, estão:

faturamento total e por mês;
ticket médio;
desempenho por vendedor e por supervisor;
produtos mais vendidos;
categorias com maior faturamento;
clientes inativos;
cidades com maior volume de vendas;
frequência de compra por cliente.
Competências praticadas

Neste projeto, pratiquei:

modelagem de banco de dados;
criação de tabelas e relacionamentos;
definição de chaves primárias e estrangeiras;
inserção de dados;
consultas com JOIN, GROUP BY, ORDER BY, COUNT, SUM e AVG;
construção de raciocínio analítico a partir de perguntas reais de negócio.
Contexto profissional

Mais do que executar comandos SQL, este projeto foi desenvolvido para demonstrar aplicação prática, conectando estrutura de dados, regras de negócio e geração de indicadores gerenciais. A proposta foi sair da teoria e construir uma entrega de portfólio com foco em clareza, organização e análise.
